# PokeForum
PokeForum

## 技术栈
- 语言：Go 1.25.5
- Web 框架：Gin v1.11.0
- ORM：Ent v0.14.5
- 数据库：PostgreSQL（支持 GIN 全文检索索引）
- 缓存/队列：Redis v9.17.2
- 认证授权：Sa-Token v0.1.7
- 依赖注入：samber/do v1.6.0
- 异步任务：hibiken/asynq v0.25.1
- API 文档：Swagger/OpenAPI

## 功能
1. 普通用户
    - 浏览帖子、评论
    - 发布主题帖、回复评论
    - 个人中心管理
    - 签到获取奖励
    - 关注其他用户
    - 收藏内容
2. 版主
    - 管理版块内容
    - 审核帖子/评论
    - 设置精华帖、置顶帖
3. 管理员
    - 用户管理（封禁、解封）
    - 帖子管理（删除、锁定）
    - 评论管理
    - 版块管理
    - 查看仪表盘统计
4. 超级管理员
    - 系统配置管理
    - OAuth 提供商配置
    - 全局设置管理

## 核心功能模块
1. 用户系统
    - 用户注册/登录/登出
    - 邮箱验证
    - 密码修改
    - 头像、签名、README 管理
    - 用户名修改（7天冷却）
    - 用户状态管理（正常、禁言、封禁、风控）
    - 用户等级系统（经验值、积分、货币）
2. 认证授权
    - 邮箱密码登录
    - OAuth 第三方登录（QQ、GitHub、Google）
    - 登录日志记录
3. 帖子系统
    - 发布主题帖（Markdown 格式）
    - 编辑帖子（3分钟冷却）
    - 设置帖子私有（3天冷却）
    - 点赞/点踩/收藏
    - 精华帖、置顶帖
    - 多级置顶（首页、版块、全局）
    - 帖子状态（正常、锁定、草稿、私有、封禁）
    - 浏览量统计
    - 全文模糊搜索（PostgreSQL GIN 索引）
4. 评论系统
    - 树形评论结构
    - 回复评论（@用户）
    - 点赞/点踩
    - 精选评论、置顶评论
    - 评论管理
5. 版块系统
    - 版块分类管理
    - 版块权限（正常、登录可见、隐藏、锁定）
    - 版块公告
    - 版块排序（权重）
    - 版主分配
6. 签到系统
    - 每日签到
    - 连续签到奖励
    - 累计签到统计
    - 签到排行榜
    - 异步任务处理签到奖励
7. 积分系统
    - 三种货币类型：积分、货币、经验值
    - 余额变动日志
    - 操作记录（包含操作者、原因、IP等）
8. 社交功能
    - 用户关注/取关
    - 黑名单管理
    - 用户主页
    - 收藏夹
9. 排行榜
    - 阅读排行榜（按时间范围）
    - 评论排行榜（按时间范围）
    - 签到排行榜
10. 管理功能
    - 仪表盘统计（用户、帖子、评论、版块数据）
    - 用户管理（查询、封禁、解封、修改角色）
    - 帖子管理（查询、删除、锁定、设置精华/置顶）
    - 评论管理（查询、删除、设置精选/置顶）
    - 版块管理（增删改查、版主分配）
    - 系统设置（站点、首页、评论、SEO、安全、功能、签到）
    - OAuth 提供商管理
11. 其他特性
    - 异步任务系统：签到奖励发放、统计数据同步（每5分钟）
    - 限流保护：全局限流（100 req/s）、API 限流（60 req/min）、认证限流（10 req/min）
    - 链路追踪：基于 UUID 的请求链路追踪
    - 日志系统：结构化日志（zap）
    - 缓存系统：Redis 缓存
    - Prometheus 监控：可选启用
    - 邮件系统：SMTP 邮件发送
    - CORS 跨域：支持跨域访问
